# 观复交易记录与理论收益复盘系统

> 致虚极，守静笃。万物并作，吾以观复。
>
> ——《道德经》第十六章

基于 Streamlit 与 SQLite 的内部 Demo。用户手工记录理论买入、卖出操作，系统按固定比例和本地参考价格计算理论交易结果，并维护理论现金、持仓、成本和盈亏。

系统的月度统计用于提供统一的理论收益基准，由业务方与其现有实际操盘统计进行人工复盘。本期不接入第三方信号，不向外部系统提交任何交易操作，也不在系统内维护实际操盘账目。

## 当前能力

- 当前跟踪统一展示观察股与理论持仓股。
- 新增观察股只需填写股票代码和名称，荐股时间由后端记录。
- 无理论持仓的观察股超过 5 个完整自然日后进入清理范围。
- 理论买入按剩余现金的 `10% / 40% / 50%` 计算。
- 理论卖出按当前单股持仓的 `50% / 100%` 计算。
- 买卖弹窗展示参考价、理论数量、理论金额和总仓占比预览。
- A 股 100 股取整、现金校验和 T+1 理论可卖数量校验。
- 理论操作记录、现金流水、持仓成本和盈亏统一落入 SQLite。
- 按股票查看不可覆盖的理论操作历史。
- 按月统计交易股数、买卖次数、累计投入、理论盈亏和理论收益率。
- 内置 5 只股票、8 笔理论操作的可重复演示数据。
- 版本化数据库迁移和自动化测试。

## 启动

```bash
source .venv/bin/activate
python -m streamlit run app.py
```

默认端口由 `.streamlit/config.toml` 管理，当前为 `8521`。也可以直接访问：

```text
http://localhost:8521
```

进入“导入与样例”，点击“载入理论交易演示数据”可重复装载样本；相同样本不会重复记账。

## 测试

```bash
python -m unittest discover -v
```

测试覆盖理论买入、理论卖出、T+1、月度统计、演示数据幂等，以及原有数据库迁移兼容性。
